# ClaimGuard

An AI agent that catches insurance claim errors BEFORE submission so hospitals don't lose revenue. 

## Demo Steps
1. Navigate to the Check Claim page and click "Load demo claim".
2. Watch Clay (the mascot) scan the documents.
3. Review the identified issues and click "Apply fix" to resolve them and see the confetti!
4. Navigate to the Appeals page to generate an AI appeal letter.
5. Check the Dashboard for insights and ROI calculator.

## Run Locally
```bash
npm install
npm run dev
```
